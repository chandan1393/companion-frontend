# Companion Atlas — Alternate Angular UI

This project keeps the existing Companion marketplace functionality, routes, API services, authentication, guards, booking flow, customer dashboard, companion dashboard, admin screens, messaging, favorites, payments and availability management.

The visual system is intentionally different from the original Companion UI:
- Forest green + warm ivory + coral + lime palette
- Editorial serif headings and Manrope body text
- Pill navigation
- Split editorial landing hero
- Dense card layouts with softer borders
- Dark dashboard navigation
- Reworked booking/payment presentation
- Responsive layouts

Backend API remains configurable through the existing Angular environment configuration.

Run:

```powershell
npm install
ng serve
```
